| Harness semantics                | Harnesses manage setup, teardown, cleanup, dependencies, and access to real behavior.                                                              | Python uses fixtures/context managers; TypeScript uses typed harness factories; Rust uses RAII guards or factories.                                                                       | Shared and mostly aligned.                                                                                                                   |
