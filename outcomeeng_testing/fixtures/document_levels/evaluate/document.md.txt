# Window readout

GOVERNS the readout of retention windows
SO THAT operators reviewing sessions
CAN RELY ON each window reading in days.

## Verification

### Evaluate: window-readout

A listing summarizer states each window in days over curated sessions. A sample
reads:

```markdown
## Not a heading

```

| Case   | Input             | Expected output              |
| ------ | ----------------- | ---------------------------- |
| ended  | an ended session  | the window reads seven days  |
| failed | a failed session  | the window reads thirty days |
