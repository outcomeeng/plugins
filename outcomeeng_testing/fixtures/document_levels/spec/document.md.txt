# Retention listing

PROVIDES the listing of ended sessions
SO THAT operators reviewing sessions
CAN find a session until its retention window elapses

## Assertions

- window-listing: ALWAYS: an ended session stays listed until its window elapses. [test: compliance, l1]

### Mapping: window-by-state

Each session state maps to the window its listing follows. [mapping]

| Case   | Window         |
| ------ | -------------- |
| active | not applicable |
| ended  | seven days     |

### Scenario: expiry

- sweep-removal: Given an ended session whose window elapsed, when the sweep runs, then the session leaves the listing. [test: scenario, l1]

### Audit

- window-observable: ALWAYS: the listing states each window in days. [audit]
