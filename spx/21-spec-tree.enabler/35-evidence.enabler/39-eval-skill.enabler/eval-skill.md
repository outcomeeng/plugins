# Eval Skill

PROVIDES generic structured-eval routing, product command binding, case-result freshness, and deterministic completion across producer-specific eval workflows
SO THAT `/verify` and producer-specific eval specialists
CAN construct `[eval]` evidence through one portable lifecycle without embedding a repository-specific runner in the shipped skill

## Assertions

### Compliance

- ALWAYS: the generic eval specialist owns product command binding, producer-kind routing, freshness inspection, serial one-case convergence, and deterministic aggregation ([audit])
- ALWAYS: eval authoring and eval-evidence auditing consume one independently loadable evidence standard ([audit])
- NEVER: the portable eval specialist embeds a product's runner package, task recipes, paths, authentication mode, or model runner ([audit])
