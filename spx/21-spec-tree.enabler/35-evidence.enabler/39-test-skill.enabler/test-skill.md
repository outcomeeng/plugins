# Test Skill

PROVIDES generic deterministic-test routing, assertion typing, execution-level selection, evidence integrity checks, and shared test workflow ceremony before language-specific expression
SO THAT `/verify`, language test skills, and test-evidence auditors
CAN construct and judge `[test]` evidence from one methodology without duplicating routing policy across languages

## Assertions

### Compliance

- ALWAYS: generic test guidance separates generated property evidence over product-owned variation from finite real-boundary evidence, keeps filesystem, Git, and full CLI work outside each generated case when it only supplies wiring, and preserves `l1` classification for cheap local boundary checks ([audit])
- ALWAYS: the generic test specialist owns test assertion typing, execution-level selection, source-contract and oracle gates, evidence-property checks, exception classification, naming policy, and evidence-summary ceremony ([audit])
- ALWAYS: test authoring and test auditing consume one independently loadable standard for coupling, falsifiability, alignment, coverage, source ownership, domain variation, oracle independence, and controlled implementations ([audit])
- ALWAYS: test authoring stops before evidence implementation until the shared standard's assertion-design record names the assertion quantifier, observable seam, case provenance, oracle owner, rejected production mutation, and resulting failure observation; moving a value preserves its provenance ([audit])
- NEVER: a language-specific test specialist owns or repeats a generic test decision ([audit])
- ALWAYS: a load-gated command `/test` runs executes in the foreground, and `/test` reports its result only after every such command has exited ([audit])
- ALWAYS: before its first write, a test-authoring round loads the language test skill of each language in which it creates or changes a test file, in a repair round as in a new scaffold, so that the language's standards bind every edit; a language with no installed test skill is reported with the result ([audit])
- ALWAYS: when `/test` repairs a source-ownership finding, it exports the value from its production owner and replaces every spelling of that value in the node's linked tests, harnesses and generators, not only the cited line ([audit])
- ALWAYS: before its first audit, `/test` sweeps the evidence it authored for every literal spelling of a source-owned value and replaces each with the production owner's export ([audit])
