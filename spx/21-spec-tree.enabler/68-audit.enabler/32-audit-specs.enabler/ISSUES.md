`just build-instructions`, whose pinned policy tuples assert literal substrings; it
changes both marketplace catalogs and the generated README catalog; it reaches
`src/plugins/instructions/skills/create-subagent/references/subagents.md`, which
carries its own plugin bump and `skill-auditor` gate; and it is a MINOR bump that
breaks `/audit-specs` invocation for every consumer.

propagating the skill rename across both plugins, regenerating the eval triggers,
