# Usage Controller

PROVIDES a scheduled, finite control pass that compacts, pauses, resumes, and stops the positions hosted in Prowl panes at the operator's configured pace
SO THAT operators overseeing several coding positions
CAN hold token spend to their subscriptions' pace without compacting, pausing, or stopping each position by hand

## Assertions

- ALWAYS: one scheduled pass every thirty minutes measures every configured position whose Prowl pane is not on the skip list, acts, and exits within five minutes; a pass that reaches that bound records its unfinished positions and leaves them to the next pass, no pass runs a daemon, watcher, or polling loop, and a pane on the skip list receives no action ([test](tests/test_usage_controller.compliance.l1.py))
- ALWAYS: a position whose context use reaches the configured compaction threshold, 30% of its window by default, receives `/compact` through the Prowl send operation at the first pass that finds its pane idle ([test](tests/test_usage_controller.compliance.l1.py))
- ALWAYS: a position whose spend over the last pass exceeds the configured compaction multiple, 1.25 by default, of its share is compacted; one that exceeds the configured pause multiple, 2 by default, on two consecutive passes is paused by the Escape key through the Prowl key operation followed by a pause notice, and resumes by the prompt `continue` at the first pass where its spend is back under its share; a position's share is its subscription's pace for the pass divided evenly among the positions of that subscription the pass measures ([test](tests/test_usage_controller.compliance.l1.py))
- ALWAYS: when a subscription's weekly use reaches the configured ceiling, 93% by default, and the operator's configuration authorizes stopping, the controller sends `/exit` through the Prowl send operation to every position on that subscription whose pane is not on the skip list, leaving each pane open, and tells the operator to switch accounts; without the stop authorization it stops nothing and reports why, below the ceiling it stops nothing, and a configured ceiling above 95% is rejected before any action ([test](tests/test_usage_controller.compliance.l1.py))
- ALWAYS: every compaction, pause, resume, and stop is a durable local record under `positions/` in the stable data root of [`spx/43-coding-agents.enabler/18-consumption-control.enabler/consumption-control.md`](spx/43-coding-agents.enabler/18-consumption-control.enabler/consumption-control.md), naming the position, the measurement, the threshold it crossed, and the reason in plain English, and delivered as consumption control delivers its alerts; no record recommends an action the controller did not take ([test](tests/test_usage_controller.compliance.l1.py))
- ALWAYS: one file, `control-positions.toml` under `$XDG_CONFIG_HOME/outcome-engineering/` and defaulting to `~/.config/outcome-engineering/`, read with the standard-library TOML reader, sets the pace per subscription, the subscription of each position, the skip list by pane title or worktree path, every threshold, the operator's authorization for the Prowl key operation, and the operator's authorization for stopping positions; an invalid file fails naming its field, a changed file takes effect at the next pass, without the key authorization the controller pauses nothing and reports why, and without the stop authorization it stops nothing and reports why ([test](tests/test_usage_controller.compliance.l1.py))
- ALWAYS: the controller takes a position's tokens only from the parser of [`spx/43-coding-agents.enabler/18-consumption-control.enabler/consumption-control.md`](spx/43-coding-agents.enabler/18-consumption-control.enabler/consumption-control.md), identified by the pane's worktree, and a subscription's weekly use and a position's context use from the Claude Code status line or Codex footer through the Prowl read operation; it paces by tokens and never by dollar cost, and a position the parser measures no session for keeps context compaction and the ceiling while its pace is reported as unmeasured ([test](tests/test_usage_controller.compliance.l1.py))
- ALWAYS: the `control-positions` skill installs, reports the status of, stops, and restarts a macOS launchd job labelled `engineering.outcome.usage-control.positions` that starts one finite pass every thirty minutes, and runs one pass on request; scheduling on any other platform returns an explicit unsupported result ([test](tests/test_usage_controller.compliance.l1.py))
- Given a configuration file and frozen consumption fixtures, when one pass runs through the `control-positions` entry point with a recording Prowl collaborator under the `/test` Stage 5 interaction-protocols case, then its records show each action the configuration selects ([test](tests/test_usage_controller.scenario.l1.py))
- NEVER: a pass measures or acts on a position whose pane the Prowl inventory does not list, so a position in a herdr pane receives no action from the controller ([test](tests/test_usage_controller.compliance.l1.py))
- NEVER: a shipped coding-agents skill other than `control-positions` instructs a position to compact another position whose pane Prowl hosts ([audit])
- ALWAYS: the controller reads token counts only through the consumption-control parser, acts on panes only through the operation surface of [`spx/43-coding-agents.enabler/18-prowl-environment.enabler/prowl-environment.md`](spx/43-coding-agents.enabler/18-prowl-environment.enabler/prowl-environment.md) by a `__file__`-relative import, resolves every path from its configuration and the installed plugin and never from a methodology worktree, calls no model, and ships no subagent definition
